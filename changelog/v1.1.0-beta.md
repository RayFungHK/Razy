# Razy v1.1.0-beta — Signed Official Registry, Scheduler, ORM Contracts, Coexistence

**Release Date:** September 2026  
**PHP:** 8.2+

The largest feature line since first public beta: the official registry went
live **and signed**, scheduling/metrics/i18n arrived, ORM gained declarative
contracts, and same-host route coexistence became a first-class concern.
24 commits, 5,238 tests. No breaking API changes; two loud deprecations.

---

## Highlights

- **Official registry, live and signed (dossier S0→S5, G4 closed)** — zero-config
  `search`/`install`/`sync`/`pkg` against `RayFungHK/Razy-Repository`; fail-closed
  SHA-256 verification on every fetch path (`Razy\PackageVerifier`); detached
  **Ed25519 signatures** over the exact `index.json` bytes verified **before**
  `json_decode` (`Razy\PackageSignature`, pinned phar-asset key). Trust is never
  silent: `[SIGNED]` / `[UNVERIFIED]` / `[SIGNATURE INVALID]` (index refused) on
  every lookup. Maintainer CLI `php Razy.phar sign` (keygen/sign/verify);
  `pkg publish --push` auto-signs when `RAZY_REGISTRY_SIGNKEY` is set.
- **Scheduler subsystem** — `Razy\Scheduler` + `CronExpression` (5-field POSIX,
  correct day-OR-dom, timezone-deterministic), fluent `call`/`command` jobs,
  `withoutOverlapping` via File/Redis locks, one crontab line via new `schedule`
  CLI. 48 tests.
- **Declarative ORM contracts (C1/C2) + visibility packs** — `Razy\ORM\Contract`
  + compiler: `create --generate` scaffolds from a contract, snapshot-drift
  detection against the live schema; visibility packs give named serialisation
  views with JSON sub-addresses.
- **Same-host route coexistence (Phases 0–3)** — host-level `exclude_paths`,
  Caddy claim scoping + FM-5 health handle, FM-2 route audit in `validate`
  (functional probes of the REAL compiled regexes) and host claim summary in
  `rewrite`.
- **Security** — zip-slip fixed in-framework (`Razy\ArchiveSafety`: hostile entry
  names rejected pre-extraction, symlinked extractions purged, HTTPS-only
  transport with env opt-out); bridge HMAC envelope (`Razy\BridgeSignature`,
  `RAZY_BRIDGE_SECRET`, ±60s window, `hash_equals`); gate hooks gained their
  first framework-level tests; `SimpleSyntax` input cap.
- **Operations** — `GET /_razy/health` (pre-boot, probe-safe payload) and
  `GET /_razy/metrics` (Prometheus; APCu-shared request counter; K8s HPA targets
  it); non-root `deploy/Dockerfile.worker` + K8s manifests + benchmark pack.
- **Async** — `Razy\WorkerPool` (persistent workers, line-JSON protocol, warm
  opcache) complements ThreadManager; `RedisQueueStore`; **`spawnPHPCode()`
  deprecated** (eval-based child; migrate to `spawnPHPFile()` / `WorkerPool`).
- **i18n backbone** — `Razy\Translation`: `Translator` (zh-Hant default, dot
  keys, module-namespaced dictionaries), `FileLoader`, `Pluralizer`
  (Laravel-compatible + CJK). Redis session driver (native TTL, SCAN GC,
  `allowed_classes=false`) ships alongside.
- **Template engine** — modifier arguments actually reach plugin code now
  (they never did), +5 modifiers, `paginate`, plugin ecosystem round; output
  safety docs and CLI honesty pass.
- **Module ecosystem begins** — first-party `modules/` home (packager resolves by
  declared `module_code`), `razymod/queue-admin` 1.0.0→1.1.0 published to the
  registry: headless queue dashboard + self-contained HTML shell (`/ui`) with
  guarded POST actions; RZ-014 tests from day one.
- **Discipline tooling** — Golden-Rules lint scanner
  (`tools/lint-module-discipline.php`), CI `redis-integration` job (no more
  silently-skipped redis suites), AI rules pack + code-verified manual rewrite.
- **Fixes** — eager-loading `with()` honoured by `first()`/`find()`
  (`getMaxStatement` deprecated: never executable); `matchDomain()`
  case-insensitive; host-only session cookies; `search` prints module codes.

## Migration

After upgrading `Razy.phar`:

1. Run `php Razy.phar rewrite` (and `caddy` claim regeneration if used) so
   same-host coexistence scoping picks up the Phase 2 output changes.
2. If you call `ThreadManager::spawnPHPCode()`, migrate to `spawnPHPFile()`
   (one-shot) or `Razy\WorkerPool::submitCode()` (repeats) — deprecation only,
   still functional this release.
3. Private registries without an `index.sig` now show `[UNVERIFIED]` banners —
   informational; signing a private registry is the `sign` CLI +
   `RAZY_REGISTRY_PUBKEY` override.
4. Deploy examples in `deploy/` now tag `worker:1.1.0-beta`; adjust any pinned
   manifests that copied the older placeholder.
