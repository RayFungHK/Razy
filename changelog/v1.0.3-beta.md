# Razy v1.0.3-beta — Subdirectory Sessions, Site URL, Module Routes

**Release Date:** May 2026  
**PHP:** 8.2+

---

## Highlights

- **Subdirectory session cookies** — `RELATIVE_COOKIE_PATH` derived from `RELATIVE_ROOT`; `Distributor::setSession()` and `Standalone::setSession()` scope PHP session cookies correctly under paths like `/abc/`.
- **`getSiteURL()` normalization** — `Distributor::getSiteURL()` wraps the composed URL with `PathUtil::tidy()` so double slashes and mixed separators do not leak into asset or route URLs.
- **`.htaccess` module routes** — Removed `library` from the index.php skip-list in `htaccess.tpl` so distributors can expose modules whose `api_name` is `library` (e.g. `/library/workspace-panel`).
- **Multisite domain registration** — `Application::updateSites()` adds every domain key to `multisite[]` (not only the first binding for a distributor code).
- **Wildcard + port** — `Application::matchDomain()` applies wildcard patterns to the hostname without port (`oaao.example.com:80` matches `*.example.com`).
- **`Agent::bind()` restored** — Register closure handlers for module-internal `$this->method()` calls without exposing them via `api('module')->method()`. Supports array batch syntax; resolved through `Controller::__call()` and the bind registry. `#command` on `addAPICommand()` remains shorthand for API + internal dual registration.

## Migration

After upgrading `Razy.phar`, run `php Razy.phar rewrite` so generated `.htaccess` picks up the skip-list change. Custom `.htaccess` patches that removed `library` from the skip-list are no longer required on v1.0.3-beta+.
