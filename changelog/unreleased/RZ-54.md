# RZ-54: `{@if}` combines a group with the operator beside it

## Fixed
- Template `{@if}` evaluated each parenthesised group on its own. `SimpleSyntax::parseParens()` turns `(0),(1)` into a group, a `,`, and a group, and `!(0)` into `!` and a group. A clip that was only an operator was skipped, so `(0),(1)` kept the last group (true) and `!(0)` never flipped (false).
- The same pass now applies `,` (and), `|` (or), `!`, and a comparison operator to the group on either side. A `,` or `|` whose following operand is also negated (`0,!0`, `1|!1`) uses that operator for the short-circuit; the `!` belongs to the next operand. An unfinished comparison such as `(1)>` is false.
