# RZ-53: version combinators after a bare version or a group

## Fixed
- `VersionUtil::vc()` read a following `,` (and) or `|` (or) only after a constraint clip (`>=1.0,<2.0`). After a bare version or a parenthesised group the operator was not a clip it understood, so the requirement was false: `0|>=1.0`, `1.2|>=2.0`, and `(>=1.0),(<2.0)`. The same skip applied to a wildcard or a hyphen range (`2.*|1.0`, `1.0 - 2.0|>=3.0`).
- The combinator is now applied after every clip. `|` still returns on the first match and `,` still returns on the first miss, left to right, including `||` written the Composer way. A clip that is not a version and not a combinator is still false. An unbalanced `(` still throws.
