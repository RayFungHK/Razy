# RZ-32: auto-escape defaults on

## Security
- A dist.php that omits `auto_escape` now HTML-escapes every `{$tag}` (ENT_QUOTES,
  UTF-8), the same rules as `'auto_escape' => true`: `->raw` and `->escape` are
  not escaped again, and a chain that ends in `->json` stays `<script>`-safe.
  Before RZ-32 the omitted key meant raw output (RZ-03).
- `validate` reads that default through `Template::autoEscapeFromConfig()`. An
  omitted key prints on. An explicit `false` prints the raw-output warning. A
  value that is not a boolean is still a boot error.

## Migration
- Sites that relied on the implicit off must set `auto_escape => false` explicitly.
- Explicit `true` is unchanged. Explicit `false` is the supported opt-out and
  still prints raw `{$tag}` output.
- A Template built with no dist config (standalone mode, and the exception page,
  which escapes its own values before assign) stays raw until
  `setAutoEscape(true)`. RZ-03's note that standalone mode does not opt in
  still holds. The change is the dist config default only.
