# RZ-18: per-request URL state for persistent workers

## Added
- `Razy\Http\RequestUrl`: the URL facts of the current request, rebuilt for every request.
  Public readonly `scheme`, `host`, `port`, `relativeRoot`, `requestUri`; `siteUrlRoot()`,
  `razyUrlRoot()`, `scriptUrl()`, `fullUrlQuery()`, `urlQuery()`; `fromServer(array $server,
  string $relativeRoot = '')` (trusted proxies applied, RZ-04), `relativeRootFrom(array $server,
  string $systemRoot)`, `current()`, `setCurrent()`.
- `NetworkUtil::isSsl(?array $server = null)`: optional server array (default `$_SERVER`).

## Fixed
- Under a FrankenPHP worker, `Distributor::getSiteURL()` / `Standalone::getSiteURL()` (and so the
  router's site URL, template links and redirects) and `XHR`'s default CORS origin used the URL
  constants defined at the worker's boot, before any request (host `UNKNOWN`). They now read
  `RequestUrl::current()`, which the worker loop rebuilds from `$_SERVER` before each request and
  clears after it. FPM and `php -S` behave as before.
- `URL_QUERY` for a request whose path is only the install root followed by a query string
  (`/abc?x=1` under `/abc`) was `x=1/` (`strtok` skips a leading `?`); it is now `/`.

## Deprecated
- The constants `HOSTNAME`, `PORT`, `SITE_URL_ROOT`, `RAZY_URL_ROOT`, `SCRIPT_URL`, `URL_QUERY` and
  `FULL_URL_QUERY`. They are still defined (from `RequestUrl`), and are correct under FPM, but under
  a worker they keep the boot values. Read `RequestUrl::current()` or `getSiteURL()` instead. They
  will be removed in the next major. `RELATIVE_ROOT` and `RELATIVE_COOKIE_PATH` are fixed per
  process and stay.
