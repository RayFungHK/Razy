# RZ-55: RedisAdapter::clear() finishes the SCAN

## Fixed
- `Cache\RedisAdapter::clear()` deleted only the keys from the first non-empty `SCAN` page. phpredis returns `[]` when that page of the keyspace misses the prefix, and `[]` is falsy, so `while ($keys = $redis->scan(...))` treated the empty page as the end of the keyspace and left the rest of the prefix.
- The loop now runs until the cursor is 0, including an empty page, the same way `Session\Driver\RedisDriver::gc()` already does. `OPT_SCAN` is not set: the `Redis` instance is shared, and `SCAN_RETRY` would change every other scan on that connection.
