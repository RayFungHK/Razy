# RZ-16: SSE abort detection, heartbeat, Last-Event-ID; `StreamProxy`

## Added
- `Razy\SSE\StreamProxy`: relays an upstream SSE/chunked HTTP stream to the client.
  `relay($url, $headers = [], $method = 'GET', $body = null, $timeout = null)` returns
  `RESULT_COMPLETED`, `RESULT_ABORTED` or `RESULT_FAILED`. It cancels the upstream transfer as soon
  as the client goes away, sends heartbeat comments while the upstream is idle, forwards the
  client's `Last-Event-ID` (a caller-set header wins), and on a transport error or upstream
  4xx/5xx logs the detail (`ErrorReporter::warn`, URL without query string) and sends the client
  only `event: error` / `data: upstream unavailable`; an upstream error body is never relayed.
  Constructor: `($sse, $connectTimeout = 10, $maxRedirects = 3)`; http(s) only.
- `SSE::__construct($retry = 3000, ?Closure $writer = null, ?Closure $abortProbe = null,
  int $heartbeatInterval = 15, ?Closure $clock = null)`: injectable output writer and abort probe
  (default `connection_aborted()`), so streams are testable without a client.
- `SSE::isAborted()` (sticky; nothing is written after it), `heartbeat()`, `heartbeatIfDue()`,
  `retry($ms)`, `lastEventId()`, `SSE::lastEventIdFrom(array $server)` (CR/LF/NUL or > 256 chars
  → null), `SSE::frame($data, $event, $id)`, `writeRaw($bytes)`.

## Changed
- `send()`: an event name or id containing CR, LF or NUL now throws `InvalidArgumentException`
  (they were silently stripped). Data is split on `\r\n`, `\r` and `\n` (a bare `\r` used to
  pass through and could start a new field on the client); NUL bytes are dropped.

## Deprecated
- `SSE::proxy()`: use `StreamProxy::relay()`. It now delegates to `StreamProxy`, so it no longer
  sends `Proxy error: <curl_error>` to the client (generic `upstream unavailable` instead) and it
  stops relaying when the client leaves. Removal in the next major.
