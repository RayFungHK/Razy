# RZ-24: the document root is not a public file tree

## Fixed
- `php Razy.phar serve` (`src/asset/setup/serve.php`) returned false for every real
  file under the document root. PHP's built-in server then downloaded that file and
  executed every other `.php`. The router no longer does that. `/data/...` is still
  served as bytes (realpath-guarded, not executed). `/webassets/...` still falls
  through to the app (RZ-09). Everything else, including `Razy.phar`, templates and
  other `.php`, is the front controller.
- Generated Caddy (`caddyfile.tpl`) used bare `php_server`. On FrankenPHP 1.13 that is
  `try_files {path} {path}/index.php index.php`, then `php` for `*.php`, then
  `file_server`, so the same tree was public. Worker mode, classic mode, the
  `@not_excluded` / `@php_claimed` gates, and the `/_razy/health` handle now rewrite
  to `/index.php` and run `php` (a `worker` block only in worker mode). FrankenPHP
  1.13 sets `REQUEST_URI` from the original request (`WithOriginalRequest` in
  `caddy/module.go`), so the rewrite does not change routing. Webasset and data
  handles are unchanged.
- Generated Apache (the `htaccess.tpl` fallback) skipped the rewrite for existing
  files (`!-f` / `!-d` / `!-l`) and for `sites`, `system`, `shared`, `plugins`,
  `asset` and the config includes. Apache then served or executed them. The fallback
  now rewrites those paths to `index.php`. Still left out: `index.php` (rewrite loop)
  and `robots.txt` (public file; missing → Apache 404).

## Migration
- Regenerate: `php Razy.phar rewrite <dist>` and `php Razy.phar rewrite --caddy`.
  The checksum watchdog would force it on the next request anyway.
- Requires FrankenPHP 1.13 or newer for the Caddy claim. Older builds that put the
  rewritten path in `REQUEST_URI` would route every URL as `/index.php`.
- Not changed here: `deploy/Caddyfile`, `benchmark/docker/Caddyfile.razy`, and the
  `^\w+/shared/` Apache rule (FM-3). Those hand-written Caddyfiles still use bare
  `php_server`. Copy the generated claim, do not copy those files, if the document
  root must not be public.
