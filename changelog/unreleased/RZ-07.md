# RZ-07: Postgres grammar for the Table/Column DSL

## Added
- `Razy\Database\Schema\PostgresGrammar`: renders `Table` (CREATE) and `TableHelper` (ALTER) as
  Postgres DDL. `SchemaBuilder::create()/table()` use it when the connection's driver is `pgsql`,
  so migrations written with the DSL run on Postgres. Multi-statement Postgres changes run in one
  transaction (Postgres DDL is transactional) unless the caller already holds one.
- `Table::getStatements($driver)`, `TableHelper::getStatements($driver)`: MySQL (and every
  non-pgsql driver) returns exactly the old single statement.
- Accessors for grammars: `Column::getParameters()`, `Table::getColumns()`,
  `Table::getGroupIndexing()`, `TableHelper::getPendingChanges()`.
- CI: the PG 16 job runs `SchemaPostgresLiveTest` (create/alter/FK/full-text against a real server,
  and `MigrationManager` migrate + rollback).

## Postgres mapping
- auto → `INTEGER`/`BIGINT GENERATED BY DEFAULT AS IDENTITY` (primary key); bool/`TINYINT(1)` →
  `BOOLEAN`; other `TINYINT`, `YEAR` → `SMALLINT`; `INT`/`MEDIUMINT` → `INTEGER`; `*TEXT` → `TEXT`;
  `DECIMAL` → `NUMERIC(p,s)`; `FLOAT` → `REAL`; `DOUBLE` → `DOUBLE PRECISION`;
  `DATETIME`/`TIMESTAMP` → `TIMESTAMP(0)`; `JSON` → `JSONB`; `*BLOB`/`*BINARY` → `BYTEA`.
- `key(index)` → `CREATE INDEX "<table>_<col>_idx"`; `key(fulltext)` → GIN over
  `to_tsvector('simple', …)`; `key(unique)`/primary stay table constraints; comments →
  `COMMENT ON`. Generated index names carry the table name (Postgres index names are schema-wide)
  and are cut to 63 bytes with a hash suffix.
- `modifyColumn()` → `DROP DEFAULT`, `TYPE … USING CAST(…)`, `SET/DROP NOT NULL`, `SET DEFAULT`.
  `dropPrimaryKey()` drops `<table>_pkey`.
- Ignored (no Postgres meaning): charset, collation, engine, zerofill, `FIRST`/`AFTER`.
- Refused with a `DatabaseException`: `ON UPDATE CURRENT_TIMESTAMP`, `SPATIAL`, `ENUM`/`SET`,
  changing a column to auto-increment.
