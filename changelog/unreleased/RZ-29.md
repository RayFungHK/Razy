# RZ-29: render UI fixtures standalone (`php Razy.phar ui list | ui render`)

## Added
- `Razy\View\Fixture`: a `*.fixture.php` file returns `Fixture::template('card.tpl')` with
  `themes()`, `widths()`, `assets(css:, js:)` (local files only), `layouts()`, `lang()`, `base()`
  and named `state()`s (a state can set its own `lang`).
- `Razy\View\FixtureRenderer`: `discover()`, `load()`, `find()`, `render()`, `write()`,
  `describe()`. A state renders into a built-in frame (`src/asset/ui/frame.tpl`) with
  `<html lang data-theme>` and the standard anchors, through the RZ-27 anchors, with auto-escape
  on. A render fails if the HTML loads anything over the network or pushes to an anchor the frame
  lacks.
- `php Razy.phar ui list [<root>…] [--json]` and
  `php Razy.phar ui render <name|file> [<state>] [--theme=] [--root=] [--out=]`. They exit 1 on
  error. There is no width option: width is the screenshot harness's viewport, read from
  `widths()`.

## Migration
- None. New command and classes only.
