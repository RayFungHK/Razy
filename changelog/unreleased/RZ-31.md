# RZ-31: `{@each}` renders every item

## Fixed
- `{@each}` set `$enclosedContent` instead of `$encloseContent`, so the body was not the loop body. The alias was assigned for every element and the body then rendered once, as the last item. The body now renders once per item.
- `{@each $items}` did not bind `source`. The parameter parser read the named-argument group, which is empty on a positional call, so the same hole dropped positional arguments for every function tag. They now bind in declaration order.

## Security
- Each iteration is substituted once. A value that contains `{$…}` or `{@…}` is text. Returning that text straight through would let the caller's `{$…}` scan execute it, so the rendered iteration is inserted by that one scan and is not scanned again.

## Migration
- A template that only ever showed the last `{@each}` item now shows every item.
- A positional call such as `{@def "name" "value"}` that previously did nothing now assigns.
