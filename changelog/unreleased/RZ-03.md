# RZ-03: template auto-escape

## Added
- dist.php `'auto_escape' => true` HTML-escapes every `{$tag}` (ENT_QUOTES, UTF-8) in the
  dist's templates, unless the tag's modifier chain contains `->raw` (trusted HTML) or
  `->escape` (already escaped). Pipe fallbacks and modifier chains are escaped on the final
  value. A value that is not a boolean is a boot error.
- New dists: the dist.php skeleton (`php Razy.phar set ... -i`) writes `'auto_escape' => true`.
- `->raw` template modifier (no-op without auto-escape).
- `Template::setAutoEscape()`, `Template::isAutoEscape()`, `Template::autoEscapeFromConfig()`,
  `Distributor::isAutoEscape()`.
- `validate` prints the dist's auto-escape posture (warning when off).
- Lint (`tools/lint-module-discipline.php`): `{$x->raw}` is an RZ-004 **error** unless the
  same or previous line has `lint-allow: RZ-004 <reason>` (a bare allow does not count).

## Compatibility
- Dists without the key keep raw output exactly as before. Opt in by adding
  `'auto_escape' => true`, then remove now-redundant `->escape` (harmless if left) and mark
  trusted HTML with `->raw`. Under auto-escape, `{$x->nl2br}` prints an escaped `<br />`;
  write `{$x->escape->nl2br}`.
- Standalone mode (no dist.php) keeps raw output; call
  `$controller->getTemplate()->setAutoEscape(true)` to opt in.
